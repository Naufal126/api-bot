LK21 Search

Cari film atau series favorit dari website LK21 berdasarkan kata kunci pencarian.

Parameters

query STRING REQUIRED

Judul film yang ingin dicari (contoh: spiderman)

Response

RESPONSE.JSON 
{
    "status": true,
    "creator": "Naufal Apies",
    "result": [
        {
            "title": "Spider-Man: No Way Home",
            "id": "spiderman-no-way-home",
            "type": "movie"
        }
    ]
}
